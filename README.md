# Hashnode Java Full Stack Blog Application

## 📌 Project Overview

Hashnode Java Full Stack Blog Application is a blogging platform inspired by Hashnode.

The application allows users to register and login, create blog posts, view posts, search posts, edit posts, delete posts, and logout.

The project is developed using Java Spring Boot for the backend, MySQL for database management, and HTML, CSS, and JavaScript for the frontend.

## 🚀 Features

- User Registration
- User Login
- Password Encryption using BCrypt
- Create Blog Posts
- View All Blog Posts
- Search Blog Posts
- Edit Blog Posts
- Delete Blog Posts
- Individual Post View
- Logout
- Responsive and Attractive User Interface
